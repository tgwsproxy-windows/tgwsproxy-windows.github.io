01 — возможности

Четыре причины
держать канал открытым

Мы не продаём абстрактную безопасность. Вот что конкретно решает TgWsProxy, если Telegram у вас работает нестабильно, медленно или не работает вовсе.

01

Обход блокировок

Трафик уходит как обычный WSS на 443-м порту. Фильтр видит легитимный TLS и пропускает его, не поднимая флаг.

Маскировка под TLS · ротация фронт-доменов · резервный маршрут

02

Стабильность

Потеря узла не рвёт сессию: клиент переезжает на ближайший живой edge за миллисекунды, не переподключаясь заново.

Health-check каждые 2 с · до 1 Гбит/с на пользователя

03

Приватность

Узлы не пишут логи соединений: ни IP, ни времени, ни объёма. Всё живёт в оперативной памяти до конца сессии.

Zero-log · MTProto 2.0 + TLS 1.3 · без привязки к телефону

04

Простота

Ни портов, ни секретов руками: Telegram сам подхватывает параметры по ссылке. Медиана до статуса Connected — 11 секунд.

Один exe · автовыбор узла · автозапуск с системой

04 — отзывы

Как вернули доступ

Три истории с согласия авторов. Имена и города изменены, вывод команд — настоящий: так выглядят типовые сценарии подключения.

case-01 · мобильный оператор
$ tgwsproxy status
→ proxy    eu-fra-01.tgwsproxy.net:8443
→ protocol wss / mtproto2
→ state    CONNECTED
→ ping     42 ms · loss 0.0%
$ _

Полгода Telegram жил только на домашнем Wi-Fi: мобильный интернет давал таймаут на каждом соединении. Подключил прокси, перезапустил клиент — заработало за одиннадцать секунд. С тех пор ни одного обрыва на перегонах.

Максим, 27 · регион с активным DPI · 214 дней с прокси

case-02 · корпоративная сеть
$ curl -s wss://ams-02/health
{ "node": "AMS-02", "status": "ok",
  "rtt_ms": 31, "dpi": "passthrough",
  "logged": false }
$ _

IT закрыл мессенджеры, а у нас на Telegram держалась вся операционка: дежурства, алерты, согласования. Согласовали прокси как исключение для одного домена — снаружи это обычный HTTPS, внутрь не лезет вообще никто.

Аня, 34 · офис на 400 человек · стабильный канал

case-03 · общежитие, слабый Wi-Fi
$ tgwsproxy route --auto-failover
→ switch   HEL-01 → STO-01 (12 ms)
→ media    stream restored
→ result   74 ms · loss 0%
$ _

Общежитие, Wi-Fi умирает каждый вечер. Прокси сам перепрыгнул на другой узел, когда первый начал тормозить, — я даже не заметил. Медиа качается, звонки не рвутся, конспекты в облаке синхронизируются.

Дамир, 22 · учёба за границей · 89 дней с прокси

05 — подключение

Три шага
до свободы

Бесплатно, без регистрации и без телеметрии. Один исполняемый файл под Windows 10/11: установщик не нужен, настройка свелась к нажатию «Запустить».

  1. 01

    Скачайте клиент

    Файл TgWsProxy_windows.exe — 4,1 МБ, Windows 10/11 x64. Установка не требуется, права администратора нужны только для системного прокси.

  2. 02

    Запустите

    Клиент опрашивает сеть, выбирает ближайший живой узел по пингу и поднимает туннель WSS/MTProto. Автозапуск с системой — одним переключателем.

  3. 03

    Проверьте статус

    В окне клиента и в настройках Telegram появится Proxy: Connected. Если узел просядет, приложение само переведёт трафик на резервный.
