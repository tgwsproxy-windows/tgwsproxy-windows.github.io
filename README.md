# TgWsProxy

Быстрый прокси для Telegram через WebSocket. Обходит блокировки там, где MTProto режется: без VPN, без логов, подключение одной ссылкой.

**Сайт:** https://tgwsproxy-windows.github.io/

## Возможности
- WebSocket-транспорт: трафик неотличим от обычного HTTPS
- Zero-log: узлы не пишут историю соединений
- Подключение в один клик, любое устройство
- Open source, бесплатно
