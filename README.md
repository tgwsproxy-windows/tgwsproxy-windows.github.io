# tgwsproxy-windows.github.io
TgWsProxy — быстрый прокси для Telegram на WebSocket-транспорте. Обычные MTProto-прокси провайдеры детектят и режут — здесь трафик упакован в WebSocket и выглядит как обычный HTTPS. Подключение одной ссылкой на любом устройстве: Windows, macOS, Linux, Android, iOS. Ноль логов, ноль рекламы, открытый код, бесплатно.
